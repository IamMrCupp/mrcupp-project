### About
A version-controlled home for the things I print — and, more importantly, the source that
generates them. Where a model is parametric it lives as OpenSCAD, so the STL is an output
you can regenerate at a different size instead of a fixed mesh you're stuck with. Organized
one directory per model.

First up is a set of sticker-holder organizer inserts — same outer footprint, different
internal grid layouts, so they drop into the same tray but sort different things. More
models land here as I build them, and some get published out to the usual sharing sites.
